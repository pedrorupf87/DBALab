# SQL Practice Problems

Os 57 problemas desta lista são do livro *SQL Practice Problems: 57 beginning, intermediate, and advanced challenges for you to solve using a "learn-by-doing" approach*, de Sylvia Moestl Vasilik (2016).

O livro é uma obra comercial e não faz parte deste repositório; os enunciados devem ser consultados no próprio livro.

O livro usa uma versão própria do banco Northwind, com pedidos entre 2014 e 2016. As respostas em [northwind-livro-sql-practice-problems.sql](../Respostas/northwind-livro-sql-practice-problems.sql) rodam no Northwind padrão (1996 a 1998): onde o livro pede 2015, a resposta usa 1997; onde pede 2016, usa 1998. Por isso os resultados não coincidem com os "Expected Results" do livro.
